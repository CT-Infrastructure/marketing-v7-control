# Portable component curation

This source-only package records147 component dispositions using repository-relative citations against the declared public source context. It preserves exact canonical software-name tokens, literal existing CP prerequisite edges, accepted native-role contracts, and native-placement evidence separately. Source naming is not proof of native runtime ownership, deployment, dependency acceptance, or production permission. Registry supports_workflows remains unconfirmed and is never the basis for new consumer mappings.

All40 conditional components remain deferred;9 legacy dispositions and9 external-channel dispositions require their respective existing owners. Unknown site facts, actual people, software versions, credentials and runtime evidence remain unresolved. No original registry, workflow, diagram or graph was changed. G02 remains held and all576 original runtime cases remain NOT_RUN.

The28 audit-finding dispositions retain original review document hashes and JSON pointers as opaque provenance. Their private locations are removed; parent-review citations are opaque labels, not files to open. Domain-citation and email-ordering changes remain technical proposals awaiting root review. The private source review is not copied as prompts or execution logs. No validator attempts to resolve opaque provenance.

Run `python -B docs/traceability/curation-public/validate_portable.py --source-root .` from a public checkout containing the declared source context. Only relative manifest paths are opened beneath that root. Symlinks, traversal, duplicate JSON keys, nonregular files, oversized files, changed source bytes and altered evidence are rejected. SHA256 comparisons normalize CRLF byte pairs to LF only, matching ordinary Git text checkout semantics; no JSON rewriting or other source normalization is allowed.

Run tests with `CURATION_SOURCE_ROOT` set to the intended read-only public checkout, then run `python -B docs/traceability/curation-public/test_portable.py`. The default source root is the containing checkout. Tests create and clean temporary synthetic fixtures beneath this package; they never write to the source checkout. A successful validator result concerns source evidence only and leaves qualification false.

Validation caches each source file's bytes after its hash check, and resolves all citations from those same bytes and a per-call parsed-JSON cache. A later validation starts with empty caches and detects changed files. Direct source relations require nonempty typed evidence and a workflow ID from the190 pinned workflow JSON records; count-preserving substitutions cannot invent a workflow. Parent and audit identities must each equal the20 canonical manager IDs without duplicates. Conditional classification and deferred disposition cannot become approval.

Audit routing uses only explicit raw `workflow_id`, `workflow_ids`, or legacy `workflows` fields. IDs must be canonical and unique; multiple fields must agree, and curated routing must match. Finding keys must be nonempty and unique. No identifier is inferred from prose. The portable manifest separates historical controller receipts from this candidate, which awaits independent controller validation.
