# Credential boundary contract 1.0

`broker.py` accepts an in-memory registry of frozen `Grant` records supplied by a trusted fixture and a separate authenticated `Context`. It exposes no issuance endpoint and no secret resolution. `authorize()` receives a grant reference plus an exact request object: schema_version, role, scope, resource and nonce. All identifiers are bounded, non-whitespace strings without wildcards. The trusted Context supplies subject/task/fence/audience/active lease; request JSON cannot substitute one. Reference grants use exact scopes from `policies/secrets/roles.v1.json`, a maximum 300-second lifetime and a per-grant one-use nonce. Success returns only SIMULATED_ALLOW and HOLD, never raw credentials or authority to perform an effect.

The constructor is the trust boundary: loading attacker-chosen grants or Context objects would grant attacker-chosen authority. A real adapter must authenticate outside the untrusted worker, protect immutable grant/policy records and verify the current lease/revocation source before calling this logic. Worker code must not host its own authoritative broker. Production operator role grants in this fixture demonstrate role separation only; a real deployment request additionally requires separately verified human approval binding outside this prototype.

`redaction.py` applies the same recursive defense to prompts, logs and artifact values. It handles sensitive structured keys, PEM private-key blocks, age private identities, GitHub-shaped tokens, model-key-shaped tokens, bearer/basic authorization, JWT-shaped strings, credential URLs and common secret assignments. Inputs and fixtures are synthetic only. Unknown objects/bytes and excessive nesting are replaced, not stringified. Formatting/redaction cannot guarantee recognition of arbitrary unlabelled, encrypted, encoded or split secrets. Production must allowlist output fields, prohibit secret input to model context, minimize raw logs, and scan at the trusted egress boundary. Do not publish a payload merely because this regex filter passed.

Run `python -B contracts/credentials/test_credentials.py` and the same command with `-O`. Tests cover role forgery, worker forbidden scopes, cross-task/fence/audience/resource use, malformed types, boundary expiry, current revocation, unavailable authority, replay and realistic fake credential redaction through all three surfaces. No test authenticates a real identity, obtains a real credential or calls an upstream service.
